# Talent Development Dashboard

[Open the live dashboard](https://nourbouazza.github.io/talent-development-dashboard/)

A lightweight, standalone dashboard for exploring a 9-box performance and potential matrix and tracking individual training plans. All included employee profiles are fictional demonstration data.

## Get started

Open `index.html` in a modern browser. No installation, server, dependencies, or build step is required.

## Features

- Place employees in the matrix by dragging them or editing their profile; filter by team.
- Manage employee profiles and individual training items, including priorities, target dates, and progress.
- Review training status and overdue items in a consolidated view.
- Customize teams, matrix labels and colors, training categories, and priorities in Settings.
- Export and import JSON backups, or reset the demonstration data.

## Data and privacy

Data is stored locally in the current browser using localStorage. It is not synchronized across browsers or devices; clearing browser data can remove it. Export a JSON backup if you need to keep or transfer your data. The application makes no network requests and uses no external services or telemetry. Use only fictional data for public demonstrations.
